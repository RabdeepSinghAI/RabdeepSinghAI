> A safer, authentic dating app that matches users through shared **music preferences** using **Gale–Shapley algorithm**, **AI chat**, and **progressive reveal**.  
> `React Native` · `Java` · `Appwrite` · `Spotify API` · `ChatGPT` · `Gemini`

### 🎾 [ATP Tennis Big Data Analysis](https://github.com/RabdeepSinghAI/atp-tennis-bigdata)
> Scalable **Apache Spark** pipeline analyzing **150,000+ ATP match records** (2000–2023). Uncovers performance trends across Grand Slams, Masters 1000, and surface types for the top 100 players.  
> `PySpark` · `Python` · `Pandas` · `Matplotlib` · `Big Data`

### 🌐 [Course Schedule — DFS Cycle Detection](https://github.com/RabdeepSinghAI/course-schedule-dfs)
> Clean **C++ implementation** of the Course Schedule problem (LeetCode #207) using **DFS with three-color cycle detection**. Passes all 52 test cases. Includes correctness proof and O(V+E) complexity analysis.  
> `C++` · `Graph Theory` · `Algorithms`

### 🧠 [Information Retrieval — Query Expansion](https://github.com/RabdeepSinghAI/information-retrieval-query-expansion)
> Uses **NLTK & WordNet** for semantic query expansion and **TF-IDF ranking**. Focus: search relevance, precision, and recall metrics.  
> `Python` · `NLTK` · `NLP` · `IR`
